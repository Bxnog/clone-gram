Feed inspirado no Instagram, com publicações de cachorros. Projeto desenvolvido como atividade do Instituto PROA, a partir do repositório espelho-espelho-meu: https://github.com/gabaugusto/espelho-espelho-meu.

## Tecnologias

- React
- JavaScript
- CSS
- Vite
- React Icons

## Funcionalidades


- Publicações e comentários carregados de arquivos JSON.
- Curtidas com contagem atualizada.
- Janela de comentários para cada publicação.
- Layout adaptável para telas menores.
